Controller core

Complete · 2026-07-16

The single-tenant control plane, built subagent-driven across 18 tasks (suite 42/42 green after the CodeRabbit fix pass): 5-crate cargo workspace — proto wire contract, embedded trust (CA + secret store + conformance suite), SQLite data model + persistent revision, single-use enrollment (bound-CIDR scoping, rebind, one-gateway-per-segment), mTLS Sync projection (snapshot + broadcast deltas + Report), key-epoch rotation bookkeeping, drain, full Admin CRUD + fabricctl + fail-closed bearer/UDS auth, declarative apply -f (idempotent, policy stubbed), authenticated UDP observation, revocation denylist + audit query/export.

Done bar proven: enroll → Sync snapshot/delta → ack → fail-static/restore against a stub gateway. Deferred by design: policy compiler (cycle 3), OpenBao (cycle 2b), data plane (cycle 4). Merged to main: PR #3 at 4ac4411, all checks green.

04

Gateway transport + relay

Pending

The gateway and relay binaries: tunnel manager (embedded boringtun, per-epoch keys), NAT traversal + brokered hole punch, relay failover, and the full NAT-matrix integration harness. Where the pending G-2 throughput gate is resolved.

Depends on: Cycle 2 (Sync client, enrollment) + Cycle 3 (enforcement backends). Reuses: relay, punch, natlab, udpshim logic. Blockers carried in (PRD v0.4): Sync-handshake rejection for revoked certs (C-9 — the tracked Cycle 2 seam); Sync version-negotiation field before the first tagged release (X-6 skew window); CA rotation + compromise runbooks executed as integration tests (C-10).

Phase 0 outcomes go / no-go per bet

Bet 1 boringtun embed + throughput go-with-caveats Embedding proven; ~7.7 Mbit/s container receive-cap unexplained. G-2 cloud run pending.
Bet 2 tc-BPF stateful ACL on tun go 5/5: default-deny, atomic A/B flip under traffic, flow table, ICMP embedded-error.
Bet 3 QUIC relay + WG-over-relay go Mandatory mutual TLS; WireGuard end-to-end through the relay at MTU 1280, boundary proven.
Bet 4 UDP observation + hole punch go Port-restricted pair punches; symmetric fails — the negative that justifies the relay.
Bet 5 NAT matrix harness go Endpoint-independent & per-destination NAT cells, behavior-asserted. Graduates to the real harness.

Open risks & carried items

Top risk
G-2 throughput gate — cloud run pending.The ≥1 Gbps target on a 4-vCPU cloud VM cannot run in the local container. First check: iperf3 -u -b 0, inspect Lost/Total, to settle whether the ~7.7 Mbit/s cap is a Docker-Desktop-VM artifact or a boringtun receive-path issue. Resolves in Cycle 4.
MVP-harden
Fail-open rule parser.An unrecognized proto string silently widens a rule to "any" — a fail-open in a default-deny product. Must become a hard parse error before rule-parsing logic ships (Cycle 3).
MVP-harden
Sync go-skew constraint (new hard requirement).Phase 0 Bet 4 found the broker's "go" must arrive within one one-way path latency, or NAT mappings self-poison. The controller's Sync brokering (Cycle 2) must honor it; spec §6.1 to be amended.
Cycle-4 blocker
Revoked/drained gateway can still open Sync (C-9).Elevated by the Cycle 2 whole-branch review; now a formal PRD requirement. Handshake-time rejection of revoked certs lands in Cycle 4 — no traffic-authz consequence until a data plane exists, but it gates the first end-to-end fabric.
Cycle-4 blocker
Sync version negotiation before first tagged release (X-6).The one-minor skew window (controller vN ↔ gateway vN-1) needs a min-supported-version field in the Sync handshake. Adding it in Cycle 4 is a field; adding it after a tagged release is a protocol migration.
Calendar-critical
External audit application fires when Cycle 3 lands.PRD §9 (v0.4): the OSTIF / Sovereign Tech Fund application goes out as soon as the policy pipeline merges — review queues run months, and the review must complete before 1.0.
Tracked fix
ICMP-echo reverse-key asymmetry.Egress records echo as {id,0}; ingress reverse lookup swaps to {0,id}, so inside-initiated echo replies don't match. ICMP errors work. Dedicated fix in Cycle 3/4.
Tracked fix
bench.sh global pkill.The throughput harness kills any iperf3/spike-tunnel process host-wide — scope it before running on the shared G-2 cloud host.
