Zero-trust network fabric — cycle-by-cycle build tracker

Open risks & carried items

Top risk
G-2 throughput gate — cloud run pending.The ≥1 Gbps target on a 4-vCPU cloud VM cannot run in the local container. Cycle 4a's real wiremesh-gateway throughput smoke test reproduced the same order-of-magnitude cap (~6.9 Mbit/s) as the Phase-0 spike binary, reinforcing the container as the likely shared cause. Bench procedure is built (crates/wiremesh-gateway/bench.md): run parallel -P 4 streams plus iperf3 -u -b 0 (inspect Lost/Total) on real 4-vCPU hardware. Does not block Cycle 4a/4b completion; still open.
MVP-harden
Fail-open rule parser.An unrecognized proto string silently widens a rule to "any" — a fail-open in a default-deny product. Must become a hard parse error before rule-parsing logic ships (Cycle 3).
MVP-harden
Sync go-skew constraint (new hard requirement).Phase 0 Bet 4 found the broker's "go" must arrive within one one-way path latency, or NAT mappings self-poison. The controller's Sync brokering (Cycle 2) must honor it; spec §6.1 to be amended.
Cycle-4b blocker
Revoked/drained gateway can still open Sync (C-9).Elevated by the Cycle 2 whole-branch review; now a formal PRD requirement. Cycle 4a now has a real data plane (previously the blocking rationale was "no data plane exists yet"), so this now has traffic-authz consequences and is carried into Cycle 4b as a real blocker, not just tracked.
Cycle-4b blocker
Sync version negotiation before first tagged release (X-6).The one-minor skew window (controller vN ↔ gateway vN-1) needs a min-supported-version field in the Sync handshake. Not built in Cycle 4a (sync.rs has no version/schema negotiation yet); adding it before a tagged release is a field, after is a protocol migration.
Fast-follow
Key rotation deferred (Cycle 4a scope decision).4a ships static single-epoch WireGuard keys, registered at enrollment via the new EnrollRequest.wg_pubkey field. Per-gateway key-epoch rotation (spec §1 decision record) is a dedicated fast-follow before Cycle 4b.
Calendar-critical
External audit application fires when Cycle 3 lands.PRD §9 (v0.4): the OSTIF / Sovereign Tech Fund application goes out as soon as the policy pipeline merges — review queues run months, and the review must complete before 1.0.
Tracked fix
ICMP-echo reverse-key asymmetry.Egress records echo as {id,0}; ingress reverse lookup swaps to {0,id}, so inside-initiated echo replies don't match. ICMP errors work. Dedicated fix in Cycle 3/4.
Tracked fix
bench.sh global pkill.The throughput harness kills any iperf3/spike-tunnel process host-wide — scope it before running on the shared G-2 cloud host.
